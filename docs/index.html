About

QDVC Stickies is a mat for sticky notes. Now takes a third of the mat, Later takes the rest, and notes go wherever you put them — except the marked channel down the middle.

Double-click the mat to start a note. Drag it by its paper, resize it from the bottom-right corner, and carry it across to the other panel whenever it changes hands.

Everything is kept in this browser's local storage. Use File → Export to carry the board elsewhere.
